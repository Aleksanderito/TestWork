# Учебные мероприятия

Небольшое SPA на React + TypeScript Данные находятся в `src/data/mockData.ts`, отдельного бэкенда нет. 

## Что есть в приложении

- список мероприятий;
- поиск и фильтр по статусу;
- просмотр информации о мероприятии в модальном окне;
- список обучающихся и ответственных;
- создание нового мероприятия;
- добавление обучающихся и ответственных из мокового списка;
- проверка обязательных полей и повторяющегося кода мероприятия.

Созданные мероприятия хранятся только в состоянии React и после перезагрузки страницы сбрасываются. 

## Запуск

Нужен Node.js 20.19+.

```bash
npm install
npm run dev
```

Для сборки:

```bash
npm run build
```

Или сборка в docker:

```bash
docker compose up --build
```
## Структура

```text
src/
  components/     компоненты таблицы и модальных окон
  data/           моковые данные
  App.tsx         состояние приложения, поиск и создание мероприятий
  types.ts        типы данных
  styles.css      стили
```
